### 📖 hi html viewer

hi html viewer是一个可以查看HTML文件的一个工具，基于tauri开发，这个工具模仿了浏览器的界面样式，支持多种功能。

### ✨ 特点

- 打开速度较快，支持打开网页文件或本地文件

- 界面整洁方便操作，支持深色主题

### 🚀 主要功能

1. 支持从本地打开文件或者从网页链接导入，又或者输入html代码等

2. 支持顶部栏拖动，也同时支持顶部栏透明化

3. 支持页面前进、后退和刷新

### ⚠️ 注意

> [!WARNING]
> 
> 这个工具运行的html环境可能存在一些问题，不适合运行一些复杂的html。
> 
> 同时也不建议小尺寸屏幕使用这个工具，会导致显示的内容出现一些问题。

### 📦 安装

可以从本仓库的Releases下载，或者下载源码构建。

### 🔨 构建应用

```bash
pnpm install
pnpm run tauri dev     # 开发模式
pnpm tauri build       # 构建应用
```
